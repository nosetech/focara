# 画面デザインプロンプト差分: バージョン表示(Claude Design 用)

issue #80。Claude Design のチャットで実際に指示した内容と、反映結果の記録です。

## 指示プロンプト

```
サイドバーのアプリ名「Focara」(実行系・整理系の両方)の下に、バージョン番号 v0.1.0 を小さい補助テキストで表示してください。フォントは IBM Plex Mono、サイズ10.5px程度、色は --ink-3 などの補助色、ロゴの左端に揃え、ライト/ダーク両テーマでコントラストが保てること。モバイルは .brand 自体が非表示なので表示しない。バージョンが取得できない場合は表示しない。整理画面と実行画面の両方に反映し、変更点を一覧で教えてください。
```

## 決定内容

- 位置: アプリ名(ロゴ+Focara)の**下**、ロゴの左端に揃える(案B)。縦の間隔は 2px。
- 見た目: IBM Plex Mono / 10.5px / line-height 1.4 / letter-spacing .02em。
- 色: デザイン側で `--ink2` に調整された(`--ink3` ではコントラスト不足のため)。
- モバイル: サイドバー(`.brand`)ごと非表示のため表示しない。
- 取得できない場合・`unknown` の場合は表示しない。
- `instance` は併記しない(任意の文字列でバージョンとは別物のため)。

## バージョンの出どころ

`backend/pyproject.toml` の `version` を正とし、`GET /api/config` の `version` で返す。`frontend/package.json` の version は表示に使わない。
