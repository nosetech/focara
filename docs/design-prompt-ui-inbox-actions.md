# Claude Design 指示プロンプト: inbox整理の行ボタン削除とタスク詳細の「習慣にする」(issue #117)

実装は先行している。Claude Design 側を実装に合わせて更新するための指示。

# 1. 整理画面: inbox整理(S4)

- 一覧の各行(フォーカス中の行)の右端に出している振り分けボタン(次にやる / いつか / 条件待ち / 習慣にする)を削除する。`Focara 整理画面.dc.html` の `S4` と `mkRow` の `actions`(inbox の行のみ)が対象。
- 残すもの: キー操作 `1`〜`4`、行をチェックしたときに画面下部に出る一括バー、画面下部のキー一覧。
- 行の右端が空くため、タイトルとメタ情報が行の幅を使うようにする。デスクトップ・モバイルの両方。

# 2. タスク詳細(`TaskDetail.dc.html`、`Focara タスク詳細・クイック追加.dc.html`)

- ステータスが inbox のタスクの詳細に「習慣にする」の操作を追加する。
- 位置は、ステータスのチップ(inbox / 次にやる / いつか / 条件待ち)の末尾。
- 見た目は、チップと同じ高さ(32px)・角丸の、破線の枠のボタン。左に習慣のアイコン(循環矢印。習慣バッジと同じもの)を置く。ステータスの選択ではなく別の操作であることが分かるようにする。
- 表示条件: ステータスが inbox のとき、かつ習慣から生成された子ではないとき。他のステータスでは出さない。
- 押すと習慣の作成シートが開く。タイトル・プロジェクト・優先度・見積もりを引き継ぎ、作成後に元のタスクを inbox から削除する。
- ライト・ダーク、パネル(デスクトップ)・シート(モバイル)の両方を用意する。
