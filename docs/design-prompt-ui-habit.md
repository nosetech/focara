# モデル
習慣は「親(習慣の定義)」と「子(その日に実行するタスク)」に分かれます。子は通常のタスクとして3枠割り当て・カレンダー・実行画面に出ます。

# 1. 習慣ページ(親の一覧。デスクトップ中心、モバイルでも閲覧可)
- 各行: タイトル、ルール要約(例: 毎週 月・水・金)、既定の枠(午前中/午後/夜)、直近7回の実施状況(完了/未完了の小さなドット列)。
- 一時停止中の習慣は薄く表示し「一時停止中」ラベルを付ける。
- 行を選ぶと右パネル(モバイルはボトムシート)に作成・編集シートを開く。
- 状態: 通常 / 空 / 読み込み中(スケルトン) / エラー(再試行)。

# 2. 習慣の作成・編集シート
項目: タイトル、プロジェクト、優先度(高/中/低)、見積、既定の枠、繰り返し(毎日 / 曜日 / 月 / 年)、開始日、終了条件(なし / 累計回数 / 終了日)、一時停止・再開、削除(確認つき)。

# 3. 子タスクのバッジ
3枠割り当て・カレンダー(日・週)・実行画面で、習慣由来のタスクに小さなバッジを付ける。

# 4. タスク詳細(子の場合)
「習慣から生成」表示、親の習慣への導線、この回だけ枠・日付を変更する操作を追加する。

# 5. inbox整理
「習慣にする」操作を追加する。押すと習慣の作成シートが開き、作成後に元のinboxタスクが消える。

# 6. 通常タスクのタスク詳細
繰り返し設定UIを外す。
